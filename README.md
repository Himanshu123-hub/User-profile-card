# Dynamic User Profile Cards 👤

## 📌 About the Project

Dynamic User Profile Cards is a simple and beginner-friendly JavaScript DOM Manipulation project. In this project, multiple user profile cards are dynamically created using JavaScript with the help of an **Array of Objects**.

Each profile card displays a user's profile picture, full name, professional recognition, and short bio.

Instead of writing HTML for every card manually, JavaScript generates all the cards dynamically and displays them inside the `<main>` element using `innerHTML`.

## 🚀 Features

- Dynamic creation of user profile cards.
- Uses an Array of Objects to store user information.
- Displays user profile images.
- Shows full name and professional designation.
- Displays a short user biography.
- Uses JavaScript `forEach()` method to iterate through the array.
- Uses Template Literals to generate dynamic HTML.
- Uses DOM Manipulation to display cards on the webpage.

5. DOM Manipulation using `innerHTML`
6. Dynamic HTML Generation

## ⚙️ How It Works

1. First, an array named `users` is created containing multiple user objects.
2. Each object stores the user's name, image, recognition, and bio.
3. The `forEach()` method iterates through every object in the array.
4. Template literals generate HTML for each user profile card.
5. All generated HTML is stored inside a variable named `sum`.
6. Finally, `innerHTML` inserts all the cards into the `<main>` element.

## 🎯 Learning Purpose

The main purpose of this project is to understand how JavaScript can dynamically generate HTML elements using DOM Manipulation.

It also helps beginners understand how to work with arrays of objects and display dynamic data on a webpage.
